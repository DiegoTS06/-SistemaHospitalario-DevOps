# Sistema Hospitalario - DevOps

Este proyecto corresponde a una práctica de DevOps para demostrar el uso de Git y GitHub.

## Objetivo

Desarrollar una pequeña base para un sistema hospitalario y aplicar buenas prácticas de control de versiones y colaboración.

## Tecnologías

- Git
- GitHub
- GitHub Flow
- Markdown

## Ramas

- main: versión principal del proyecto.
- develop: rama de desarrollo.
- feature/login: rama para desarrollar el inicio de sesión

## Flujo de trabajo

Los cambios se desarrollan en ramas independientes y posteriormente se integran mediante Pull Requests hacia la rama develop.
